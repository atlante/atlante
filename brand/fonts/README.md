# Bundled fonts

These are upright, Latin-subset variable WOFF2 files bundled with Atlante's public logo exports and design
specimens. The files are vendored so rendering does not depend on a third-party font request or a changing
CDN response.

| Family         | File                                       | Axes                          | Google Fonts revision |
| -------------- | ------------------------------------------ | ----------------------------- | --------------------- |
| Bodoni Moda    | `bodonimoda/bodoni-moda-latin.woff2`       | `opsz 6..96`, `wght 400..900` | `v28`                 |
| Source Serif 4 | `sourceserif4/source-serif-4-latin.woff2`  | `opsz`, `wght 200..900`       | `v14`                 |
| Source Sans 3  | `sourcesans3/source-sans-3-latin.woff2`    | `wght 200..900`               | `v19`                 |
| JetBrains Mono | `jetbrainsmono/jetbrains-mono-latin.woff2` | `wght 100..800`               | `v24`                 |

Each family retains its own `OFL.txt`. Add a matching subset and update the
relevant license file when adding an italic or non-Latin face.
